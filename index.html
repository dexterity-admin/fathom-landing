Questions?

Everything you need to know before downloading.

Is Fathom really free? What's the catch?
Yes, the Free tier is genuinely free forever — no trial, no credit card, no account. It includes instant name/path search, image/text/markdown preview, command palette, themes, and tray/hotkey. The "catch" is we hope you love it enough to upgrade to Pro for content search, treemap, dedup, and auto-organize.
Does my data leave my machine?
Never. Fathom is local-first by design. The search index, your settings, and your files all stay on your disk. There's no telemetry, no cloud sync, no account required. License validation is offline (HMAC-signed keys).
What platforms are supported?
Windows 10 1903+ (x64/ARM64), macOS 12+ (Intel & Apple Silicon universal DMG), Linux (AppImage, .deb, .rpm, Snap, Flatpak — glibc 2.28+).
How does content search work? Is it slow?
Content search uses ripgrep + an incremental SQLite index. First index takes minutes on large drives; subsequent updates are near-instant via filesystem watchers. Search latency stays under 100ms even on 1M+ files.
Can I try Pro before buying?
Yes — every Pro feature is visible but gated in the Free tier. Click any Pro feature to see a demo of what it does. When ready, enter a license key (purchased from our site) to unlock instantly. No re-download needed.
What's the difference between monthly and annual billing?
Annual gives you 2 months free (17% off). Pro: $9.99/mo → $99/yr. Team: $29/user/mo → $290/yr. You can switch anytime; unused time is prorated.
How does the license key work? Do I need an account?
No account needed. Purchase → receive an HMAC-signed key (e.g., FATHOM-PRO-…) → paste into Fathom once. It validates offline. Team plans use a central license file + optional SSO hook.
Is there a portable version?
Yes — Windows portable (no install, runs from USB) is a Pro feature. Linux AppImage is inherently portable. macOS doesn't have a true portable build due to Gatekeeper.
What file types does content search support?
PDF, DOCX, XLSX, PPTX, Markdown, plain text, and 50+ code languages. More formats added regularly — see the full list.
How do I report a bug or request a feature?
Open an issue on GitHub. We tag bugs with bug and feature requests with enhancement — votes help prioritize.
